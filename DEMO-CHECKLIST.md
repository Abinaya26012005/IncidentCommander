# Demo checklist

## PRE-DEMO

- [ ] dependencies installed
- [ ] ports free
- [ ] Commander, PayFlow and ConverseLab start
- [ ] all health endpoints pass
- [ ] all three websites load
- [ ] dark/light theme works
- [ ] AI Context assets load
- [ ] no active stale incident
- [ ] PayFlow healthy
- [ ] ConverseLab healthy
- [ ] Live AI status accurately says NOT CONFIGURED when applicable
- [ ] deterministic fallback available

## PAYFLOW

- [ ] healthy payment
- [ ] source fault injection
- [ ] traffic and pool increase
- [ ] payment failure and UNKNOWN incident
- [ ] evidence, Git/source, traces and negative dependency evidence
- [ ] AI Context candidate comparison and integrity
- [ ] RCA, risk, approval and patch execution
- [ ] 18/18 fresh verification
- [ ] pool healthy, payment succeeds, RESOLVED and postmortem

## CONVERSELAB

- [ ] healthy chat and voice
- [ ] TTS fault injection
- [ ] voice fails while text succeeds
- [ ] scoped UNKNOWN incident
- [ ] TTS evidence and healthy STT/Knowledge/LLM evidence
- [ ] AI Context, RCA, remediation and approval
- [ ] 5/5 voice and 3/3 chat verification
- [ ] RESOLVED and postmortem

## ADAPTIVE CONTEXT

- [ ] JSON, TOON and HYBRID measured
- [ ] profiler and AUTO router
- [ ] token/byte measurement
- [ ] minimum saving policy
- [ ] round-trip and Evidence Integrity
- [ ] Token Budget
- [ ] redaction and safe fallback
- [ ] application isolation
- [ ] RCA, memory, Copilot, postmortem and UI integration

## FINAL REGRESSION

- [ ] context unit/UI/HTTP tests
- [ ] PayFlow and ConverseLab tests
- [ ] isolation and UNKNOWN safety
- [ ] evidence-ID, patch safety, approval and verification tests
- [ ] Copilot, postmortem and theme tests
- [ ] full regression
