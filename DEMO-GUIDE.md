# Judge demo guide

## Story

PayFlow is a normal checkout. A real local source regression exhausts its connection pool. Commander discovers the UNKNOWN incident from independent evidence, prepares a validated AI context, proposes a narrow repair, waits for approval, and verifies fresh traffic. ConverseLab then demonstrates the same architecture against a different application and a TTS boundary failure.

## Opening script

“This is one Commander monitoring two independent applications. The applications keep normal JSON APIs. Commander adapts only the context sent toward reasoning, and every optimization is rejected if it changes evidence.”

## Thirty-second context explanation

“Incident investigations can generate large repetitive AI contexts. IncidentCommander profiles the RCA context and evaluates JSON, TOON and Hybrid representations. It measures tokens and bytes, validates round-trip correctness and evidence integrity, checks the context budget, and selects the best valid representation. If an optimized representation loses critical evidence, it is rejected and the system safely falls back.”

## Judge sequence

Show Commander Applications, PayFlow healthy checkout, the PayFlow incident, AI Context details, evidence strength, approval, fresh verification and postmortem. Then show ConverseLab healthy chat/voice, inject TTS failure, show upstream negative evidence, approve restoration, verify five voice plus three chat, and return to a healthy customer experience.

Never claim live external AI, real banking, real speech or arbitrary repair.
